## 1. プロジェクト概要

### 1.1 背景・目的

「年金を繰り下げると受給額は増える。でも実際の手取りはどれだけ増えるのか」——この問いに正確に答えられるツールは、現状ほとんど存在しない。

厚生労働省の公的年金シミュレーターは年金受給額の試算はできるが、税・社会保険料の計算は**年金収入のみ・単身者前提・受給開始時点の1時点のみ**であり、就労収入や配偶者収入との合算、年齢による負担の変化は考慮されていない。

本プロジェクトでは、ねんきん定期便の年金見込み額を起点に、受給開始年齢・就労収入・配偶者収入・iDeCoなど複数の収入を合算した上で税金と社会保険料を計算し、**実際の手取り額と生涯受取総額を受給開始年齢ごとに比較できる**Webアプリケーションを開発する。

「繰り下げると手取りがどう変わるか」「何歳まで生きると繰り下げが得か」を定量的に可視化することで、ユーザーが年金受給タイミングを自ら判断できるよう支援する。

### 1.2 対象ユーザー

- 年金受給開始年齢（繰り上げ・繰り下げ）を検討している50〜70代の個人
- 繰り下げによる手取りの実態を正確に把握したい方
- 就労収入や配偶者収入がある中での年金手取りを知りたい方

### 1.3 提供価値

| 提供価値 | 説明 |
|---------|------|
| 手取り年金額の正確な算出 | 税・社会保険料を控除した実際の手取り額を計算 |
| 複数収入との合算計算 | 就労収入・配偶者収入・iDeCo等を合算した世帯ベースの税・保険料計算 |
| 年齢ごとの負担推移 | 65歳・75歳などの節目で税・保険料がどう変化するかを可視化 |
| 受給開始年齢の比較 | 60〜75歳の各開始年齢での手取り額・生涯受取総額を一覧比較 |
| 損益分岐点の明示 | 「何歳まで生きると繰り下げが得か」をグラフで直感的に表示 |
| データの永続化 | 入力値をブラウザに保存し次回アクセス時に復元 |

### 1.4 競合との差別化

**公的年金シミュレーター（厚労省）との比較**

| 機能 | 公的年金シミュレーター | retirement-vision |
|------|-------------------|-----------------|
| 年金受給額の試算 | ✅ | ✅（ねんきん定期便の金額を直接入力） |
| 繰り上げ・繰り下げ試算 | ✅ | ✅ |
| 税・社会保険料の計算 | △ 受給開始時点のみ | ✅ 年齢ごとの推移 |
| 計算の前提 | 単身・年金収入のみ | 世帯ベース・複数収入合算 |
| 就労収入との合算 | ❌ | ✅ |
| 配偶者収入との合算 | ❌ | ✅ |
| iDeCo・企業年金との合算 | ❌ | ✅ |
| 損益分岐点の明示 | △ 弱い | ✅ |
| データの保存・復元 | ❌ | ✅ |

### 1.5 スコープの定義

本アプリは「**年金を軸にした手取り最適化ツール**」に特化する。金融資産の運用・枯渇管理は対象外とし、asset-visionの領域とする。

| スコープ内 | スコープ外 |
|-----------|---------|
| 年金手取り額の計算・比較 | 金融資産残高の管理 |
| 税・社会保険料の計算 | 資産枯渇年齢の計算 |
| 受給開始年齢の最適化 | 生活費・大型支出の管理 |
| 複数収入の合算計算 | 資産運用利回りのシミュレーション |

## 2. 機能要件

### 2.1 基本情報入力

| 入力項目 | 単位 | デフォルト値 | 説明 |
|---------|------|------------|------|
| 現在の年齢 | 歳 | 60 | — |
| 性別 | 男/女 | — | 平均余命の参照に使用 |
| 想定寿命 | 歳 | 90 | 85・90・95・100から選択 |
| 配偶者の有無 | あり/なし | — | 配偶者収入・加給年金の計算に使用 |
| 配偶者の年齢 | 歳 | — | 配偶者ありの場合 |

### 2.2 年金情報入力

#### 2.2.1 公的年金

| 入力項目 | 単位 | デフォルト値 | 説明 |
|---------|------|------------|------|
| 年金見込み額（65歳受給時） | 万円/年 | 180 | ねんきん定期便の「老齢基礎年金＋老齢厚生年金の合計額」を入力 |
| 年金受給開始年齢 | 歳 | 65 | スライダーで60〜75歳を設定 |
| 配偶者の年金見込み額（65歳受給時） | 万円/年 | 0 | 配偶者のねんきん定期便の合計額 |
| 加給年金 | あり/なし | — | 配偶者が65歳未満の場合に適用（約39万円/年を自動加算） |

**ねんきん定期便の見方**

ねんきん定期便に記載されている「65歳からの年金見込み額」の合計額（老齢基礎年金＋老齢厚生年金）をそのまま入力する。

- **50歳以上**：現状維持で働き続けた場合の見込み額が記載されているため、そのまま入力できる（推奨）
- **50歳未満**：これまでの加入実績のみの金額が記載されており将来分が含まれないため、下記の概算計算を補助的に提供する

**50歳未満向けの概算計算（補助機能）**

ねんきん定期便の金額が実態に合わない場合は、以下の入力から概算額を自動計算してセットする。

| 入力項目 | 単位 | 説明 |
|---------|------|------|
| 国民年金の納付済み月数 | ヶ月 | 最大480ヶ月（40年） |
| 厚生年金の加入年数 | 年 | 会社員・公務員として勤務した年数 |
| 平均年収（税込） | 万円/年 | 厚生年金加入期間の平均 |

```
老齢基礎年金 ≒ 81.6万円 × 納付済み月数 / 480
老齢厚生年金 ≒ 平均標準報酬月額 × 5.481/1000 × 加入月数
年金見込み額 = 老齢基礎年金 + 老齢厚生年金
```

**繰り上げ・繰り下げによる年金額の自動計算**
- 繰り上げ受給（60〜64歳開始）：1ヶ月あたり −0.4%
- 繰り下げ受給（66〜75歳開始）：1ヶ月あたり +0.7%
- 受給開始年齢スライダーを動かすと年金額・手取り額がリアルタイム更新

#### 2.2.2 その他の収入

| 入力項目 | 単位 | デフォルト値 | 説明 |
|---------|------|------------|------|
| 就労収入 | 万円/年 | 0 | 退職後のパート・フリーランス等 |
| 就労終了年齢 | 歳 | — | 就労収入がある場合 |
| iDeCo受取額 | 万円/年 | 0 | 年金形式で受け取る場合 |
| iDeCo受取開始年齢 | 歳 | 65 | — |
| 企業年金受取額 | 万円/年 | 0 | DB/DC等 |
| 不動産収入 | 万円/年 | 0 | 家賃収入等 |

### 2.3 税・社会保険料計算機能

全収入を合算した上で以下を計算する。計算には東京都新宿区の基準値（令和6年度）を使用し、その旨を画面上に明記する。

#### 2.3.1 公的年金等控除

年金収入額と年齢に応じた控除額を計算し課税対象の雑所得を算出する。

**65歳以上の場合**

| 年金収入（年額） | 控除額 |
|---------------|-------|
| 110万円以下 | 110万円（実質ゼロ課税） |
| 110万円〜330万円未満 | 収入 − 110万円 |
| 330万円〜410万円未満 | 収入 × 25% + 27.5万円 |
| 410万円〜770万円未満 | 収入 × 15% + 68.5万円 |
| 770万円以上 | 収入 × 5% + 145.5万円 |

**65歳未満の場合（繰り上げ受給時）**

| 年金収入（年額） | 控除額 |
|---------------|-------|
| 60万円以下 | 60万円（実質ゼロ課税） |
| 60万円〜130万円未満 | 収入 − 60万円 |
| 130万円〜410万円未満 | 収入 × 25% + 27.5万円 |

#### 2.3.2 所得税・住民税

```
課税所得 = 合計所得 − 公的年金等控除 − 基礎控除（48万円） − 社会保険料控除
所得税  = 課税所得 × 累進税率（5%〜45%）× 1.021（復興特別所得税）
住民税  = 課税所得 × 10% + 均等割（5,000円）
```

#### 2.3.3 社会保険料

**介護保険料（65歳以上）**
- 東京都の平均的な基準額（約7,000円/月）をベースに所得段階別の倍率を適用

**後期高齢者医療保険料（75歳以上）**
- 東京都広域連合の保険料率を使用
- 均等割（約4万円/年）+ 所得割（約9%）

**国民健康保険料（退職後〜75歳未満）**
- 東京都の平均的な保険料率を使用
- 医療分 + 支援金分 + 介護分（40〜64歳）で計算

#### 2.3.4 在職老齢年金

就労収入がある場合、給与と年金の合計が月50万円を超えると年金が減額される計算を適用する。

### 2.4 計算式のまとめ

```
手取り額 = 年金収入 + その他収入
         − 所得税
         − 住民税
         − 介護保険料
         − 医療保険料
         （− 在職老齢年金による減額）
```

### 2.5 結果表示機能

#### 2.5.1 サマリーカード

現在設定している受給開始年齢での結果を表示する。

| 指標 | 説明 |
|------|------|
| 年金月額（額面） | 繰り上げ・繰り下げ後の年金額（万円/月） |
| 年金月額（手取り） | 税・保険料控除後の手取り（万円/月） |
| 手取り率 | 手取り ÷ 額面（%） |
| 生涯手取り総受取額 | 想定寿命までの累計手取り（万円） |
| 損益分岐点年齢 | 65歳受給と比較して累計手取りが逆転する年齢 |

#### 2.5.2 グラフ表示

**グラフ①：受給開始年齢別 手取り額の比較（棒グラフ）**
- X軸：受給開始年齢（60〜75歳）
- Y軸：年間手取り額（万円）
- 額面・所得税・住民税・社会保険料・手取りを積み上げ棒グラフで表示
- 「繰り下げるほど額面は増えるが税・保険料も増える」が一目でわかる

**グラフ②：生涯手取り総受取額の比較（折れ線グラフ）**
- X軸：年齢（受給開始〜想定寿命）
- Y軸：累計手取り受取額（万円）
- 受給開始年齢ごとの累計手取りを複数ラインで重ねて表示
- 各ラインの交差点が損益分岐点年齢として視覚化される

**グラフ③：年齢別 税・社会保険料の推移（積み上げ面グラフ）**
- X軸：年齢（受給開始〜想定寿命）
- Y軸：負担額（万円/年）
- 所得税・住民税・介護保険料・医療保険料の内訳を積み上げ表示
- 65歳（介護保険開始）・75歳（後期高齢者医療開始）の節目での変化を可視化

#### 2.5.3 受給開始年齢別 比較テーブル

60〜75歳の各受給開始年齢について一覧表示する。

| 受給開始年齢 | 年金額（額面） | 税・保険料 | 手取り年額 | 手取り率 | 損益分岐点年齢 |
|-----------|------------|---------|---------|---------|------------|

#### 2.5.4 年齢別 収支詳細テーブル

設定した受給開始年齢での年齢ごとの詳細を5歳刻みで表示する。

| 年齢 | 年金収入 | その他収入 | 所得税 | 住民税 | 介護保険料 | 医療保険料 | 手取り合計 |
|------|---------|---------|------|------|---------|---------|---------|

### 2.6 感度分析（リアルタイム更新）

以下のパラメータをスライダーで変化させると全グラフ・テーブルがリアルタイムに更新される。

- 年金受給開始年齢（60〜75歳）
- 就労収入（月額）
- 想定寿命

## 3. 非機能要件

### 3.1 パフォーマンス

| 項目 | 要件 |
|------|------|
| 計算・グラフ更新 | パラメータ変更後100ms以内にリアルタイム更新 |
| 初期表示 | 3秒以内（LCP） |

### 3.2 対応環境

| 項目 | 対応範囲 |
|------|---------|
| ブラウザ | Chrome / Firefox / Safari / Edge（最新2バージョン） |
| デバイス | PC・タブレット・スマートフォン（レスポンシブ対応） |
| 画面解像度 | 375px〜1920px |

### 3.3 ユーザビリティ

- 各パラメータにツールチップで説明を表示
- ねんきん定期便のどこを見れば良いかの説明を入力欄付近に表示
- 入力データはブラウザのローカルストレージに保存し次回アクセス時に復元
- 計算根拠（使用した税率・保険料率）の確認ページを用意
- 結果のPNG/PDFエクスポート機能

### 3.4 データの取り扱い

- 入力データはブラウザのローカルストレージのみに保存（サーバー送信なし）
- 個人情報・年金情報はサーバーに送信しない

## 7. 考慮事項・制約事項

### 7.1 計算上の前提・簡略化

- 年金額の計算はねんきん定期便の見込み額を入力値として使用する（独自に算出しない）
- 税金・社会保険料の計算は東京都新宿区の基準値（令和6年度）を使用。居住地によって実際の金額と異なる場合がある
- 配偶者控除・医療費控除等の各種所得控除は基礎控除・社会保険料控除のみ考慮
- マクロ経済スライドによる年金額の将来的な調整は考慮しない
- 税制・保険料率の将来的な改正は考慮しない

### 7.2 免責事項

本ツールの計算結果はあくまで参考値であり、実際の年金受給額・税額・保険料を保証するものではありません。正確な年金額はねんきんネットまたは年金事務所でご確認ください。
